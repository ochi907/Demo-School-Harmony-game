# โครงงานคอมพิวเตอร์ เกี่ยวกับการจัดการปัญหาวัยรุ่น

## ที่มาและความสำคัญของโครงงาน
  ในปัจจุบันโลกแห่งการศึกษาได้ก้าวหน้าและพัฒนาไปเรื่อย ๆ  รูปแบบการเรียนรู้ก็ต้องปรับปรุงเปลี่ยนแปลงเพื่อให้เข้ากับยุคผุ้เรียนจะมีการเรียนรู้ที่ยืดหยุ่น สร้างสรรค์ ท้าทาย และมีส่วนร่วมในกิจกรรมการเรียนรู้ไปพร้อม ๆ กับผู้สอนไม่ใช่หาหาความรู้จากตำราเพียงอย่างเดียว แต่ปัญหาที่พบคือผู้เรียนมักจะไม่มีความกล้าที่จะแสดงความคิดเห็นหรือตอบคำถามต่าง ๆ จึงทำให้ผลการเรียนรู้ไม่มีประสิทธิภาพเท่าที่ควร

ผู้จัดทำจึงมีแนวคิดที่จะสร้างแอพพลิเคชันเพื่อสนับสนุนการกัดกิจกรรมที่จะช่วยสร้างแรงจูงใจให้กับผู้เรียนได้แสดงความคิดเห็น ตอบคำถามโจทย์ต่าง ๆ ในรูปแบบของเกม ซึ่งจะมีลักษณะเป็นโลกจำลองให้นักเรียนเลือกบทสนทนาให้ตอบโจทย์กับกับประเด็นสังคม เช่น การถูกกลั่นแกล้ง ความเครียดจากการเรียน  เพื่อให้ตรงกับจุดประสงค์การเรียนในหัวข้อนั้น ๆ นอกจากนี้ยังสามารถสอดแทรกความกิจกรรมความรู้ต่าง ๆ เข้าไปในเกม เพื่อให้ผู้เรียนได้รับรู้ที่หลากหลายมากขึ้นอีกด้วย

## วัตถุประสงค์
```
เพื่อแนะแนวและให้ความรู้นอกจากการเรียนรู้ในห้องเรียน
เพื่อเพิ่มทักษะด้านการคิดวิเคราะห์และการพัฒนาการเขียนโปรแกรม
เพื่อให้บุคคลภายนอกเข้ามาศึกษา และนำไปเป็นกรณีศึกษาต่อ
```
